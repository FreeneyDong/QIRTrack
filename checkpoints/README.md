# Checkpoints

Download the legacy S9 diagnostic checkpoint from the [Model Zoo](../docs/MODEL_ZOO.md)
and save it here as `s9_b256_seq_got_64k.pt`. The binary is ignored by
Git. See [manifest.json](manifest.json) for its SHA256 and compatible tracker.
This legacy S9 was trained with ARTrackV2-Base256-seq-GOT and is not a final
benchmark checkpoint.
